# 日本語長尺台本制作スキル（固い床 × 自由舞台）

映像・サムネイルと同じ **「固い床（事故防止の最低限基盤）× 自由舞台（テーマ次第の自在な設計）」** で台本を制作する。
演出・Spec設計は各ハーネス入口スキル（[harness-stickman-collage](../harness-stickman-collage/SKILL.md) /
[harness-plan-e-macro-econ](../harness-plan-e-macro-econ/SKILL.md) /
[harnesses/README.md](../../../harnesses/README.md)）へ委譲する。

参照正本: [style_guide.md](../../../configs/style_guide.md) /
ch1 [harnesses/stickman-collage/README.md](../../../harnesses/stickman-collage/README.md) /
ch2 [09_plan_e_longform_blueprint.md](../../../docs/evergreen/09_plan_e_longform_blueprint.md)。

## 1. 固い床（全フォーマット共通・必ず守る基盤）

1. **一次情報3ソース以上＆法務/YPPガードレール（Gate 1）:**
   - `01_research_brief.md` に一次情報3ソース以上と、その回固有の問い・視点を確定する。
   - 執筆前にタイトル・サムネ案・`clickConfirmPromise` を仮確定する（[thumbnail-design](../thumbnail-design/SKILL.md) Gate 1）。
   - YMYL非助言・ACML 1.0批判利用禁止・名誉毀損/不競法回避・出典は概要欄のみ（動画画面内表記なし）を厳守する。
2. **2ファイル分離と整合（Gate 2）:**
   - `02_script_display.md`（チャンクID・演出メモ・概要欄転記用出典メモ）と
     `03_script_reading.md`（同一チャンクID・TTS読み上げ専用原稿）を内容整合で分離出力する。
3. **読み上げ原稿の純度:**
   - `03_script_reading.md` へのト書き・英語演技指示・Markdown/HTML装飾の混入ゼロ。
   - TTS誤読しやすい語は適宜ひらがな化・桁カンマ除去・`%`→`パーセント` 等の前処理を行う。
4. **冒頭と末尾の最低限規律:**
   - 冒頭の挨拶・自己紹介・登録/高評価依頼ゼロ。
   - 末尾の終了合図語（「いかがでしたでしょうか」「ご視聴ありがとうございました」等）および禁止語尾ゼロ。
5. **機械検証（固い床 ERROR 0）:**
   ```powershell
   .\pipeline\.venv\Scripts\python.exe pipeline/scripts/lint_script.py <台本ディレクトリ>
   ```
   **固い床 ERROR 0** で通過させる。WARNING（TTS前処理：誤読漢字・桁カンマ・%・未カナ英字）およびリズム/尺/「間」メトリクスは
   推敲の参考材料として確認し、文脈優先で採否判断する（WARNING 0 は強制しない）。

## 2. 自由舞台（テーマとチャンネルに合わせて自在に設計）

以下は固定型に縛られず、その回のネタが一番面白くなる形を選ぶ。

- **企画・視野:** ch1は行動科学・心理に閉じず（人体・進化・科学・歴史・生き物・言葉・確率・AI・社会・心理など）
  「人間や世界のバグ・奇妙な仕組み」を解体。ch2はマクロ経済・家計ニュースに閉じず（恋愛・医療・スポーツ・アート・
  エンタメ・冠婚葬祭・家電・歴史・教育・都市など）「お金とインセンティブの構造」を赤ペン解剖する。
  英語直訳のような翻訳調タイトルを避け、日本語ネイティブの感覚で刺さる表現にする。
- **導入の切り口:** 思考実験・逆説データ・日常の違和感・具体エピソード・質問など、最も引きが立つ切り口を自由に選ぶ。
- **章立て・展開ブロック・尺:** 尺（15〜25分等）はあくまで目安とし、水増しせず一次情報と面白さに見合う自然な尺・構成へ着地させる。
- **リフック・章末・結び:** 疑問形・反転・事実の予告・余韻など、流れに合う繋ぎ方を選ぶ。末尾は挨拶締めを避け、自然な着地や次動画導線で切る。
- **リズムと日本語表現:** 短文連打や長文の緩急、自然な日本語表現、海外題材での固有名詞は文脈優先で自由に使う。
  専門用語や統計は視聴者の生活実感へ噛み砕く。
- **チャンネル別の語り口（指針であり型ではない）:**
  - **ch1『バグる棒人間』:** 丁寧な敬体を基調に、上から目線を避けて軽快・知的・ユーモラスに並走する。
  - **ch2『経済の赤ペン』:** 丁寧な敬体を基調に、事実とインセンティブの矛盾を静かに刺す乾いた知的シニカル調で語る。
- **視聴維持と「間」の制作ガイド（制約ではなく参考指針）:** 構成や尺は固定せず自由だが、長尺の維持率を支える目安として
  「冒頭15秒の約束（期待値一致）」「3分目のリフック」「中盤の転換点」を意識し、結論・反転・オチの要所では
  人間らしい「間（呼吸・緩急）」が活きる流れを作る。間の書き方（純度を保つ方法）は
  [style_guide.md §1.4](../../../configs/style_guide.md) を参照。

## 3. 推敲・人間リライト

- **NG語リストによる細かい表現縛りは設けない。** 固い床（ERROR 0）さえ守れば、モデルの自然な日本語表現力を最大限に活かす。
- 冒頭30〜90秒と要所を中心に人間が音読し、聴感・間・緩急を整える。
- 要所の短い呼吸は 03 の本文の書き方（句点で切る・短い一文を独立させる）で作り、0.8秒以上の長い間は
  Spec の `pauseAfterSec`（ch1 shot / ch2 chunk）で入れる。「（間）」「[pause]」などのト書きは入れない（固い床 ERROR）。

## 4. 完了検証

- `lint_script.py` が **固い床 ERROR 0**（2ファイル整合・ト書き/英語指示ゼロ・冒頭挨拶ゼロ・終了合図語ゼロ）で通過すること。
- `01_research_brief.md` に一次情報3ソース以上・独自の問い・仮確定パッケージが揃い、法務/YPPガードレールを満たしていること。
- 冒頭から挨拶なしで引き込み、読み上げ原稿が自然な日本語口語として耳で違和感なく通ること。
