# YouTube-video-engine

日本市場向けの完全非属人・長尺（15〜25分）YouTubeチャンネル制作および海外バズフォーマット検証・異常値発掘のための統合プロジェクトリポジトリ。

## 確定している基本方針

1. **ゴール:** 2027年2月1日のYPP新基準（総再生時間 4,000時間 → 8,000時間）適用前に、反映ラグ・AdSense確認・審査期間を含め旧基準（登録者1,000人・4,000時間）の一発合格を目指す。
2. **検証アプローチ:** 海外バズ動画の冒頭60秒をGeminiネイティブ動画解析 → `studio/`（Remotion）で非公開ベンチマーク再現 → 人間の差分修正を `configs/style_guide.md`・`studio/src/components/`・`.agents/skills/` へ定着させて日本語オリジナルへ展開する。
3. **フォーマット・チャンネル方針（現行2本柱）:**
   - **ch1『バグる棒人間』**（`stickman-collage` v2.1 / `stickman_collage`）：行動科学・心理に限定せず、人体・進化・科学・歴史・生き物・言葉・確率・AI・社会・心理など幅広いジャンルから「人間や世界のバグ・奇妙な仕組み」を2D棒人間で解体。
   - **ch2『経済の赤ペン』**（`plan-e` v3.1 / `planE_macro_econ`）：マクロ経済・家計ニュースに限定せず、恋愛・医療・スポーツ・アート・エンタメ・冠婚葬祭・家電・歴史・教育・都市など幅広いジャンルを「お金とインセンティブの構造」で赤ペン解剖。
   - **廃止・除外（新規制作禁止）:** 旧ハーネス全般（案A・案B・案C路線A・旧案Cシネマ・重い3D系/案D）。
4. **疎結合・非ロックイン:** 特定ツール・モデル・サブスクに固定しない。ツール選定と単価・期限は `configs/stack.yaml`・`configs/pricing_watch.yaml`・`docs/volatile/` に分離し、いつでも差し替え可能に保つ。

## ディレクトリ構成

| パス | 役割 |
| :--- | :--- |
| `AGENTS.md` / `CLAUDE.md` | 常駐エージェントルール（超軽量・詳細参照ポインタ） |
| `.agents/skills/` | 作業時のみ展開するオンデマンド手順（ベンチマーク再現・法務監査・台本・Remotion・スタック更新） |
| `docs/decisions/` | プロジェクト憲章（`000`）と人間が意思決定すべき未決・矛盾事項（`001`） |
| `docs/evergreen/` | 普遍的原則（絶対ガードレール・フォーマット・制作工程・成長戦略・収益化・異常値数理） |
| `docs/volatile/` | 変化の速い情報（AIスタック単価・YPP/API規約・日本市場/税務＋更新ログ） |
| `docs/sources/` | Google Drive リサーチ原本7本（通常作業時はコンテキスト投入禁止） |
| `configs/` | ロール別スタック設定・価格監視・異常値しきい値・文体/視覚スタイルガイド |
| `studio/` | Remotion 2Dコード駆動モーショングラフィックス環境 |
| `pipeline/` | Python YouTube異常値発掘・導線抽出・Gemini Two-Pass解析基盤 |
| `episodes/` | ベンチマーク再現および本番エピソード制作管理（YPP再審査用人間関与証跡を兼ねる） |

## 開発環境セットアップ概要（手動実行用）

本リポジトリ初期構築時点では依存パッケージのインストール・有料API実行は未実施である。稼働時に以下を手動実行する。

- **Remotion (`studio/`):** `cd studio && npm install && npm run dev`
- **Python パイプライン (`pipeline/`):** Python 3.11+ 環境で `cd pipeline && pip install -e .`（環境変数は `.env.example` を `.env` にコピーして設定）
