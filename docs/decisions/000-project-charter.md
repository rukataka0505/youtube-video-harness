- **制定日:** 2026-11-21
- **ステータス:** 確定（リサーチレポート7本の記述と矛盾する場合は本憲章が優先する）

## 1. 最上位ゴール

- **2027年2月1日**の YouTube パートナープログラム（YPP）新基準施行（公開長尺総再生時間 4,000時間 → 8,000時間、Shorts 1,000万回 → 2,000万回）の前に、**旧基準（登録者 1,000人・有効総再生時間 4,000時間）での一発合格**を目指す。
- 反映ラグ（YouTube Studio Earn タブ反映まで通常 2〜7日）、AdSense ステップ2承認（新規数日〜最大2〜3週間）、ステップ3本審査期間（1週間〜約1か月）、および1月否認時の30日再申請待機リスク（＝自動的に新基準8,000時間へ転落）を逆算し、**2027年1月31日 23:59 UTC（日本時間 2027年2月1日 08:59）前の承認または確実なステップ3到達**を死守する。

## 2. 検証および資産化アプローチ

量産に入る前に、以下のクローズドループで品質と再現性を確立する。

1. **海外バズ構造抽出:** 海外ヒット長尺動画の冒頭60秒を、Gemini ネイティブ動画解析（Two-Pass Static Hybrid の Pass 1）で秒・フレーム・構成単位の JSON へ分解する。
2. **非公開ベンチマーク再現:** `studio/`（Remotion）を用いて、抽出した冒頭60秒のテンポ・図解・2層テロップ・演出を非公開（テスト）で再現実装する。
3. **人間差分修正の資産定着:** 人間による違和感修正・演出ブラッシュアップの差分を言語化し、以下に還元する。
   - 文体・デザイン規則 → `configs/style_guide.md`
   - 再利用Reactコンポーネント → `studio/src/components/`
   - 作業手順 → `.agents/skills/`
4. **日本語オリジナル展開:** 定着した型を用いて、日本市場向けのオリジナル長尺（15〜25分）制作へ展開する（単なる翻訳・焼き直しは禁止）。

## 4. 技術スタックの疎結合・非ロックイン原則

- 2026年11月21日時点の初期候補スタックは、**Google AI Ultra（Gemini 4系・Flow / Omni 1.2 Flash）＋ Claude（Opus 5.5 / Sonnet 5.5）＋ Remotion ＋ DaVinci Resolve Studio 21.1** とする（なお **AI画像生成は動画・サムネイルともに不使用** とし、実写写真・見出し・図版・公的資料・フリー素材のネット収集＋Remotion 2Dコード描画/SVGで完結させる）。
- ただし特定ベンダー・モデル・サブスクリプションへのロックインを禁止する。
- **不変層（`docs/evergreen/`）** と **変動層（`docs/volatile/`・`configs/stack.yaml`・`configs/pricing_watch.yaml`）** を分離し、サービス終了（にじボイス、OpenAI Sora/Sora 2 等）や価格改定（2026/12/1・2027/1/1等）時に設定・カタログの差し替えのみで安全に移行できる構造を維持する。
