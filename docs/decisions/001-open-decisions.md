# ADR-001: 7本横断で検出した矛盾点と人間が意思決定すべき事項

初期リサーチレポート7本（`docs/sources/01` 〜 `07`）の突き合わせにより検出した**相互矛盾**、および確定前提を踏まえて**着工前に人間が決定すべき事項**を整理する。

---

## A. 人間が意思決定すべき重要事項（着工前ゲート）

### 決定事項1：ナレーション音声スタックの最終確定（ACML 1.0 罠の回避）

- **レポート間の矛盾:**
  - `06` / `07` は、日本語固有名詞の正確性と低コスト（月額1,980円無制限）から **Aivis Cloud API（プレミアム）** の常時利用や、無料音声との併用を推奨（一部「ACMLモデルなら商用OK」と記述）。
  - `02`（第4.1節）は、AivisHub 主要モデルに適用される **ACML 1.0 ライセンス全文に「主張が正当であるかどうかにかかわらず、実在する人物・団体・商品などを批判する活動への利用禁止」条項がある** と警告（さらに非営利限定 `ACML-NC 1.0` も混在）。また `02` / `03` は 2026年9月30日東京地裁「声のパブリシティ権」判決や YouTube 類似性検出、`03` は「にじボイス」終了の教訓から既製合成音声の脆弱性を警告している。
- **本リポジトリの暫定処理:** `02` の法務防衛を絶対ガードレールとして優先採用し、**既製 ACML 1.0 モデルの批判動画利用を禁止**した。
- **決定すべき選択肢:**
  - **案1（最推奨・法務＆YPP安全度最大）:** **自分の声のボイスクローン**へ統一（ElevenLabs Creator $22〜 / Pro $99 の PVC v4、または AivisHub 非公開自声モデル「まるなげボイス」税抜15万円、あるいは Gemini 3.8 Flash TTS 本人同意レプリケーション※SynthID付与）。
  - **案2（案C・案B/E限定での初期軽量案）:** 実在企業・商品批判を一切含まない企画に限り、ElevenLabs 有料既製商用ボイス または AivisHub の **CC0（パブリックドメイン）** モデルのみで開始し、チャレンジ枠（案A）着手前に自声クローンまたは宅録ナレーターへ移行。
  - **案3（買切ローカル重視）:** `VOICEPEAK 商用可能6ナレーターセット`（DL版 ¥23,800）を採用（ただし CLI が1回140字上限・Windows環境制約あり）。
- **決定ステータス:** `[ ] 未決定`

### 決定事項4：初動の投稿ペース・Shorts併用・人間工数水準・5%実写枠の扱い

- **レポート間の矛盾:**
  - 長尺投稿ペース：`01` は「事前5本バッチ → 初週3本段階公開（Day 1/3/6） → 2週目以降 **週2本**」、`03` は「Phase 1 月4本（週1）→ Phase 3 週2本」、`06` は「**週3本（月12本）**」、`07` は「黄金ペース **週2本**（最大週3本）」。
  - Shorts併用：`01` は登録者1,000人の壁突破のため **週1本（比率33%上限）の専用縦型未完結Shorts** を強く推奨。`06` / `07` は長尺制作中心で言及が薄い。
  - 人間工数：`06` は **1本3時間（175分）**（冒頭90秒リライト）、`07` は **1本7.5時間**（冒頭30秒リライト＋5%実写・実機インサート）。
  - 5%実写インサート：`07` は AIスロップ回避に「動画尺の5%（20分で60秒）の実写／手元／実機画面録画」を推奨するが、確定前提の主力は **2D・コード駆動系（案C / 案B・E）**。
- **決定すべき事項:**
  1. 定常投稿ペースを **長尺週2本**（推奨：ベンチマーク再現と品質維持両立）にするか **週3本** にするか。
  2. 登録者獲得用の **専用縦型Shorts（週1本・比率33%以内）** を初週から組み込むか。
  3. 2D・コード駆動系における「5%一次素材枠」を **実画面録画・一次資料スキャン・Remotion独自データ可視化** で代替し、実写撮影を不要とするか。
- **決定ステータス:** `[ ] 未決定`
