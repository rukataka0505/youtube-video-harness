# 01. 絶対ガードレール（素材利用・企業法務・音声・YPP審査防衛）

本ファイルは本プロジェクトにおいて**いかなる制作効率化や再生数追求よりも優先される普遍的防衛ライン**を定義する。法務・契約・YPPポリシーに抵触しない安全な範囲でのみ企画・台本・映像・収益導線を設計すること。

## 1. ビジュアル素材調達・引用・出典表記の実務ガイドライン

本リポジトリの全フォーマット（動画本編・サムネイル共通）では、以下の3方針を統一基準とする。

1. **AI画像生成は使用しない:** 動画素材・サムネイル素材ともに AI画像生成は使わない。ネット上から実写写真・新聞・ニュース見出し切り抜き・図版・公的資料・フリー素材・関連画像を積極的に収集・活用し、不足分や図解は Remotion 2Dコード描画・SVG等で補う。
2. **著作権を気にしすぎない実務スタンス:** 海外・国内の先駆者解説チャンネルの運用実態を参考にしたうえで、動画内での解説・批評に伴う引用や関連素材利用の程度であれば実務上問題ないと判断する。過度に萎縮した自主規制（「記事見出し切り抜き禁止」「関連写真禁止」「すべてSVGで自力描画」等）は設けない。
3. **出典表記は概要欄のみに集約:** 動画画面内（画面隅のクレジットテロップ・出典バッジ等）での著作権・出典表記は原則行わず、必要な出典元・クレジットはすべて YouTube 概要欄のみに集約して記載する。

### 1.1 素材別の現実的な運用ライン

| 素材カテゴリ | 積極活用（標準運用） | 避けるべきライン（致命的リスクの回避） |
| :--- | :--- | :--- |
| **ニュース記事・見出し切り抜き** | 見出し・リード・紙面カード等の切り抜きやWeb記事スニペットを解説の裏付け・視覚アクセントとして積極的に活用。 | 有料記事の全文掲載、記事本文の丸ごと転載やそのまま読み上げ。 |
| **関連写真・公式Web・図版** | 話題の対象を直感的に伝える関連写真・公式Web画面・製品イメージ・公的資料・フリー素材をネット上から積極的に収集し活用（※AI画像生成は不使用）。 | 解説を伴わない丸ごと転載や、公式チャンネル・公式提携と誤認させる悪質なサムネイル加工。 |
| **IR・決算資料・政府統計（EDINET / e-Stat等）** | 該当スライドや図表の引用、または見やすさ・アニメーション演出に応じた Remotion 2Dチャート描画を自在に使い分ける。 | 資料PDFの全ページ連続垂れ流し。 |
| **企業ロゴ・商標** | 解説対象を識別するための社名表記・ロゴ表示（文脈上必要な範囲での利用）。 | 公式提携・公式アカウントと誤認させるなりすまし演出。 |
| **SNS・Web上の話題・引用** | 企業公式発表や文脈紹介のための抜粋・カード表示。 | 一般ユーザー投稿を無断で大量収集して並べるだけの「反応集」量産（YPP非真正リスク・トラブル要因）。 |
| **書籍・論文・調査レポート** | 複数ソースから知見・数値・一節を引用・統合し、独自の切り口で解説構成。 | 単一書籍・論文・有料レポートの丸ごと要約（翻案）や有料部分の全文転載。 |

### 1.2 出典表記のルール（概要欄のみに集約）

- **動画画面内では著作権・出典表記を行わない:** 画面隅のクレジットテロップ・出典バッジ・カード内出典フッター等を動画画面内に常設・表示してテンポや画面美観を損なう運用は行わない。
- **YouTube 概要欄のみへの集約:** 使用したニュース記事・統計データ・関連図版・公的資料などの出典・クレジット表記が必要な場合は、すべて YouTube 概要欄（「参考資料・出典」ブロック等）のみに集約して記載する。

## 2. 企業法務・広告規制リスク防衛（特にチャレンジ枠 案A 必須）

1. **名誉毀損の違法性阻却3要件（民法709/710条・刑法230条）：** 法人も社会的評価の主体。①公共性、②公益目的、③真実性・真実相当性をすべて満たすこと。意見・論評型でも前提事実の真実性と「人身攻撃に及ばないこと」が必須。
2. **信用毀損・偽計業務妨害（刑法233条）：** AIハルシネーションの検証漏れで「倒産寸前」「粉飾」「欠陥製品」等の虚偽を流布すると刑事・民事リスクが現実化。一次資料3ソース以上での人間ファクトチェックを絶対ゲートとする。
3. **不正競争防止法第2条1項21号（営業誹謗）：** 大阪地裁令2.11.10判決により、A社を批判し競合B社のアフィリエイトへ誘導する投稿者は「競争関係」が認定される。**批判・解剖対象企業の競合アフィリエイト／PRリンクは絶対に貼らない**。
4. **経営者個人リスクと情プラ法：** 法人＋代表者個人が共同原告になると賠償額が跳ね上がる（東京地判令6.9.24で計385万円事例）。また情報流通プラットフォーム対処法（2025/4施行）により大規模事業者は原則7日以内削除判断が必要。「無能」「詐欺」等の人格攻撃・未確定犯罪の断定を厳禁とする。
5. **対立・批判テーマ時の実務配慮（Content ID / 削除申立リスク管理）：** 実在企業を強く批判する企画（案A等）では、長尺の公式動画・CM映像の流用によるContent IDブロックや削除申立トラブルを避けるため、必要に応じた短い引用・見出し切り抜き・公的データ・図解を中心にメリハリをつけて構成する（過剰な全面禁止にはせず、概要欄での出典整理と事実ベース論評を徹底）。
6. **景表法（ステマ規制）＆金商法（37・38条）：**
   - 途中再生を前提に、案件・アフィリ紹介区間中は**画面内に常時「【PR】／広告／アフィリエイト」テロップ**＋**概要欄1〜3行目（折りたたみ前）の明記**＋（対価・提供・指示あり案件は）Studio「有料プロモーション」ONを徹底。企業案件契約には「二次利用時もPR表記維持」条項を入れる。
   - 証券・投資・金融教育トピックでは「必ず儲かる」「絶対に損しない」等の断定・特定銘柄売買推奨を排除し、元本割れリスク注記と同等サイズ表記を徹底。
   - 心理・行動科学（案C）は医学診断・治療の代替ではない旨を明示し、健康食品/サプリ案件時は薬機法遵守。

## 3. 音声・技術・音楽ライセンスの絶対境界

1. **Aivis Cloud / ACML 1.0 の「正当な批判でも禁止」条項:**
   - AivisHub主要モデルが採用する `ACML 1.0` は「**あなたの主張が正当であるかどうかにかかわらず、実在する人物・団体・商品などを批判・攻撃する活動への利用**」を明文で禁止し、`ACML-NC 1.0`（非営利限定）も混在する。
   - したがって実在企業・商品を批評する動画（案A等）への既製 ACML 1.0 モデル使用は厳禁。**最優先は自分の声のボイスクローン**（有料プラン）または `CC0`・独自契約音声とする。
   - 2026年9月30日東京地裁（声のパブリシティ権一般論明示）およびYouTubeの類似性申し立て（Likeness Claim）を踏まえ、特定の著名人・声優・実在人物に似せた音声は絶対に使用しない。
2. **有料プラン契約境界:** AI画像生成は方針上不使用。生成音声や必要時のAI B-Roll動画は無料プラン・Beta対象外生成物を本番利用せず、必ず商用利用可能な有料プラン上で生成する。
3. **Remotionライセンス（外注合算3名上限）:** Free License は個人および**外部パートナー合算3名以下**の小規模法人のみ。Remotionコードを触る外注を含め4名以上に達する場合は Company License 契約または完成MP4調整のみへの外注分離を行う。
4. **クラウドレンダリング時のフォント規約:** AWS Lambda / Docker / CI 等でレンダリングする場合、Adobe Fonts や Morisawa Fonts のサーバー配置・ファイル同梱は契約違反。**Google Fonts（Noto Sans JP等）・源ノ角ゴシック・源暎フォント等の SIL OFL 1.1 / Apache License 2.0 フォントに完全統一**し、ライセンス文を同梱する。
5. **BGM・AI生成音楽:** Suno / Udio 等のAI生成音楽は排他的権利がなく、他者酷似曲の Content ID 先行登録による収益移転リスクが高いため本編メインBGMには使用しない。Content ID クリアランス済みの商用ライブラリ（Safelist登録）に限定する。

## 4. YPP「非真正コンテンツ」一発合格・再審査防衛ルール

1. **2026年7月明確化「非真正コンテンツ」NG類型への完全対策:**
   - **汎用・反復テンプレ回避:** 直近3本を連続再生しても「名詞だけ入れ替えた量産品」に見えないよう、1本ごとに一次情報3ソース以上・異なる物語骨格（時系列／対比／通説反転）・固有のRemotion図解・固有の概要欄解説を作成する。
   - **不快・怒り煽り回避:** 過度な煽り・復讐スカッと構成・無関係クリップ継ぎ接ぎを排除する。
   - **センシティブ領域のAIペルソナ禁止:** 金融・医療/健康・法律・政治で「AI生成キャラクターが専門家（医師・投資顧問等）のふりをして助言する演出」は一発不承認対象のため全面禁止。
2. **審査官の6大確認ポイント:** ①チャンネルの主テーマ一貫性、②最多再生動画、③最新動画、④総再生時間シェア最大動画、⑤タイトル・サムネ・説明欄、⑥チャンネル［概要］欄（制作方針と一次調査・自作図解の明記）。
3. **AI開示ラベル（改変/合成コンテンツ）の正確な運用:**
   - **ON（「はい」）必須:** 実在人物・出来事の改変、実写と見分けがつかないリアル調AI B-Roll、動画の主題となるAI音楽。
   - **OFF（「いいえ」）準拠:** 台本補助・字幕・2Dアニメーション/Remotion図解・**自声クローン**・薄い背景BGM。
4. **アカウント・BAN連鎖防衛:**
   - 同一運営者（同一AdSense・Googleアカウント・IP・デバイス）配下で1チャンネルでも収益化停止やBANを受けると全チャンネルへ連鎖停止し得る。テスト用・グレー実験（切り抜き・反応集等）を同一環境で絶対に走らせない。
   - ブランドアカウントで運用しオーナーは本人のみ（管理者付与は原則ゼロ、やむを得ない外注はMP4受渡で完結）。
   - **YPP申請〜承認完了まで公開済み動画を一切削除・非公開・限定公開にしない**（有効総再生時間が即日消滅するため）。
5. **万一の不承認・事前通知時「動画再審査請求」5条件:**
   - ①既存動画を一切削除しない、②期限厳守（不承認/停止は21日以内、事前通知は7日以内）、③5分未満・限定公開・対象チャンネル自身から新規投稿・説明欄に再審査情報を書かない、④冒頭30秒以内にチャンネルURLを表示、⑤自身の肉声＋制作証跡（一次資料リサーチ・台本Git差分・Remotionコード/DaVinciタイムライン実画面録画）で人間主導を証明する。
