# 02. 採用フォーマット設計と日本ローカライズ変換ルール

本プロジェクトは海外で構造的再現性が実証されたフォーマットの「骨格」を抽出し、日本語ネイティブ視聴者の行動特性へ創造的変換（トランスクリエーション）して長尺（15〜25分）で展開する。

---

## 1. フォーマット採否ポートフォリオ（現行2本柱）

### 主力①（ch1『バグる棒人間』）：`stickman_collage` v2.1 — 2D棒人間×背景極性×人間・世界のバグ解体（多ジャンル）
- **海外ベンチマーク:** `easy, actually`、`The Paint Explainer`、`Horses` 等
- **テーマ・基本構造:** 行動科学・認知心理に限定せず、人体・進化・科学・歴史・生き物・言葉・確率・AI・社会・心理など幅広いジャンルから「人間や世界のバグ・奇妙な仕組み」を棒人間で解体する。通説への逆張り命題と学術研究・一次事実・日常あるある小ボケ → 視点転換（リフレーム）→ 実践指針や新たな視点。
- **ビジュアルと文体:** 8種生きた背景（`PolarityBackground`）× 関節リグ棒人間（`RiggedStickman`）× 実写/紙面コラージュ × 自由 TSX 演出。丁寧な敬体（「です・ます」）。詳細は `harnesses/stickman-collage/README.md`。
- **長尺化ルール:** 尺（15〜25分等）はあくまで目安とし、水増しせず一次情報と演出密度に見合う自然な尺・章立てで組む。
- **法務境界:** 医療診断・治療の代替ではない旨を明示し、架空AI専門家アバターは禁止。

### 主力②（ch2『経済の赤ペン』）：`planE_macro_econ` v3.1 — 逆説・シニカルなお金とインセンティブ構造解剖（多ジャンル）
- **海外ベンチマーク:** `How Money Works`（検証記録: [`episodes/benchmarks/how-money-works-destroy-economy/`](../../episodes/benchmarks/how-money-works-destroy-economy/)）
- **テーマ・差別化（重要）:** マクロ経済・家計ニュースに限定せず、恋愛・医療・スポーツ・アート・エンタメ・冠婚葬祭・家電・歴史・教育・都市など幅広いジャンルを「お金とインセンティブの構造」で赤ペン解剖する。棒人間・動物メタファーは使わず、「逆説・インセンティブ解剖 × 物理質感の紙面/黒板/実写 B ロール自由舞台」で構成する。
- **ビジュアルと文体:** 7種サーフェス（`SURFACE_POLARITY`）の明暗極性交差と赤ペン注釈・データ図解で、シニカルかつ品格のある丁寧な敬体で語る。正本: [`09_plan_e_longform_blueprint.md`](./09_plan_e_longform_blueprint.md) / `harnesses/plan-e-macro-econ/README.md`。
- **長尺化ルール:** 尺ありきの水増しをせず、YMYL金融断定を避けつつ一次データと構造解剖の密度に見合う自然な尺で組む。

### 除外・廃止確定（新規制作禁止）
- **廃止済み旧ハーネス全般:** 旧・案A（企業興亡シネマ）、旧・案B（MSペイント単体）、旧・案C（路線A / 旧シネマ Aperture型）、重い3D系（案D：`fern` / `Green Dot Aviation` / `Branch Education` 型）はすべて廃止・削除済み。
- **二次活用のみ許容:** 既存15〜25分動画に新規ブリッジ解説と図解変化を加えた60〜90分総集編（公開比率15〜20%以下）。

## 2. 海外直輸入が日本で失敗する6大パターン

`Kurzgesagt` 日本語版や単純自動吹替が伸び悩む背景にある構造的罠を回避する。

1. **未調整TTS・自動吹替による違和感:** 同音異義語誤読（「生憎」「人気」「最中」「十分」「施行」等）、数字後の不自然区切り、文脈温度とズレた抑揚は即座に「AI量産品」と判断され離脱を招く。
2. **欧米型ミニマルサムネの情報不足と煽り直訳の胡散臭さ:** 「1〜3語＋余白」では何の動画か伝わらず、「INSANE!」「SCAM!」直訳は日本の視聴者に強い釣り警戒心を与える。
3. **無字幕によるモバイル・消音視聴離脱:** 日本は移動中・消音視聴需要およびテレビ番組由来のテロップ文化が強く、視覚文字情報がない動画は弾かれる。
4. **長い前置き vs 雑な結論隠し:** 30秒以上の前置きは視聴維持率を急落させ、逆に中身を出し惜しみすぎる構成も離脱される。
5. **生活文脈・法制度の未変換:** 米国固有制度や舞台のままでは自分事化が起きない。日本の商習慣・制度・身近なブランド、または普遍的心理・経済原理へ置き換える。
6. **海外「YouTube自動化（テンプレ量産）」の無思考模倣:** 毎回同一の導入・BGM・スライド構造・記事読み上げは「非真正コンテンツ」停止対象となる。

## 3. 日本市場最適化「成功の変換4ルール」

### 変換ルール①：パッケージ設計（サムネイル × タイトル分業）
- **台本前に仮確定:** 動画制作後にサムネを後付けで盛ると期待値ギャップで冒頭離脱が起きるため、企画段階でサムネ構図・コピーを仮確定させる。
- **サムネイル（感情フック担当）：**
  - 文字数は **上限 20文字・2行以内**。スマホ縮小で0.5秒で読める文字サイズを保つため **推奨3〜10文字程度**。書体は固定せず題材で選ぶ（ゴシック・明朝等、SIL OFL / Apache 2.0）。
  - 要素や画面内小文字を盛りすぎるとスマホ縮小時に広告チラシや資料に見えてスルーされやすいため、**主役・モチーフは2〜3個程度に絞り、小文字も極力省くことを推奨**。
  - 4大心理トリガー（①具体数字、②損失回避、③意外性、④自分ごと化）から **1〜2種類の掛け合わせ** に絞る。
  - 右下再生時間バッジ領域（`1920×1080` 右下 `220×84px`）を避け、大差2〜3案で明暗極性・視覚メタファーに加え、切り口・フック軸ごと検証できるよう**コピーも固定せず各案に最適な文言を振ることを推奨**（スマホ `168×94px` 縮小スクイントテスト必須）。
- **企画・タイトル立案（広い視野＆脱翻訳調）：**
  - 特定ジャンルに閉じず広い視野で案を出す（ch1は行動科学・心理に限定せず多ジャンル、ch2はマクロ経済・家計ニュースに限定せず多ジャンル）。
  - 英語直訳のような翻訳調を避け、日本語ネイティブの感覚に自然に刺さる言い回しを使う。
- **タイトル（検索・文脈詳細担当）：**
  - **全角30文字前後**を目安に、英語直訳調を避けたクリックしたくなる自然な日本語にする。「検索KW先頭」「`【】`活用」は任意オプション。サムネの丸写しは避けつつ、主題語1〜2語の自然な共有で0.5秒で文脈が噛み合う状態にする。

### 変換ルール②：冒頭・構成の設計方針（固い床 × 自由舞台）
- **固い床:** 冒頭の挨拶・自己紹介・登録依頼を完全に省き、末尾の終了合図語（「いかがでしたでしょうか」「ご視聴ありがとうございました」等）を廃止する。**冒頭30秒維持率 60%標準・70%優良（50%以下は改善対象）** を目安とする。
- **自由舞台:** 導入の切り口（思考実験・逆説データ・日常の違和感・エピソード等）、章立て・展開ブロック、リフックや章末の形、尺の長さはテーマに合わせて自在に設計する（定型時間割は強制しない）。以下は20分尺の参考構成例。

| 区間目安 | 役割（一例） | 設計の狙い |
| :--- | :--- | :--- |
| **導入** | スクロール停止フック〜導入 | 挨拶ゼロでサムネの期待を素早く確証し、本題へ引き込む。 |
| **序盤〜中盤** | 展開・構造解剖 | 一次情報と視点転換で中だるみを防ぎ、必要に応じて小完結やリフックを挟む。 |
| **終盤** | 回収・独自考察・次導線 | 張った問いを誠実に回収し、挨拶締めを排して余韻や次動画導線で切る。 |

### 変換ルール③：テンポ・BPM同期と2層テロップ
- **視覚変化の周期:** `stickman_collage` は最大4.5秒、`planE_macro_econ` は `PLAN_E_AUDIT_RULES.MAX_BEAT_GAP_SEC` 以内に視覚変化を入れ、**長時間の完全静止を禁止**する。
- **意図的な「間」:** 無音を機械的に全て詰めず、結論・反転・オチの要所で間を効かせる。短い呼吸は読み上げ原稿の本文（句点・短文）で作り（ト書き禁止）、0.8秒以上の長い間は Spec の `pauseAfterSec`（ch1 shot / ch2 chunk）や BGM 引き算で入れる（`configs/style_guide.md` §1.4）。
- **2層テロップ構造:**
  - 下段：**常時ベース字幕**（1行 18文字以内目安・最大2行、1.0〜3.0秒表示、抜け感アウトラインで消音視聴・CTV対応、読み上げ原稿と一言一句一致）。
  - 中央〜上部：**重要キーワード・金額・年号のモーション強調**（図解連動）。テレビバラエティ風の過剰な多色テロップ装飾は排する。

### 変換ルール④：2ファイル分離・文体方針
- **2ファイル分離（固い床）:** 画面表示用台本（`02_script_display.md`）とTTS読み上げ原稿（`03_script_reading.md`：ト書き・英語指示・装飾除外、誤読対策済み）を同一チャンクID・内容整合で分離する。
- **文体と推敲（自由舞台）:** 現行2チャンネルとも丁寧な敬体（「です・ます」）を基調とし、短文連打や長文の緩急、自然な日本語表現、海外題材の固有名詞は文脈優先で自在に使う。NG語リストによる表現縛りは設けず、固い床（ERROR 0）さえ守ればモデルの自然な日本語表現力を活かし、聴感・間・緩急は音読で整える（詳細は `configs/style_guide.md`）。
