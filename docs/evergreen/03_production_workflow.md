# 03. 制作ワークフローと技術規格（AI 8割 × 人間 2割）

本ファイルは、特定のAIモデルやソフトウェア製品に依存しない**モジュラー半自動制作パイプライン**と、**海外ベンチマーク再現→資産定着ループ**、およびCTV・モバイル両立の普遍的技術規格を定める。具体的なツール割り当てと単価は `configs/stack.yaml` および `docs/volatile/stack_catalog.md` を参照すること。

---

## 1. 最重要プロセス：海外バズ冒頭60秒ベンチマーク再現 → 資産化ループ

オリジナル企画の量産へ入る前、および新演出パターンの獲得時には、必ず以下の5ステップで型を検証・資産化する。

```text
[1] 海外ヒット動画選定（異常値スコア / 拡散率確認）
      ↓
[2] Gemini動画解析 Pass 1（冒頭60秒・2.0 FPS・High Res → HookMicroSpec JSON抽出）
      ↓
[3] Remotion 非公開ベンチマーク再現（studio/src/compositions/benchmarks/）
      ↓
[4] 人間による差分レビュー＆直接修正（テンポ・間・文字サイズ・配色・視認性の違和感解消）
      ↓
[5] 差分を資産へ昇格・定着
     ├─ デザイン・文体法則 → configs/style_guide.md
     ├─ 再利用UI/図解パーツ → studio/src/components/
     └─ 手順・禁止事項     → .agents/skills/
      ↓
[6] 日本語オリジナル長尺（15〜25分）制作へ展開
```

- ベンチマーク再現動画は**非公開テスト専用**とし、外部公開しない。
- 定着させるのは「固定の丸ごとコピー用テンプレート」ではなく、**組み合わせ可能な最小部品（カード・グラフ・セーフフレーム・2層テロップ）とタイミング規則**である（YPP「非真正コンテンツ」対策）。

## 2. AI 8割 × 人間 2割：全7ゲート分業マトリクス

AI10割の自動化は「日本語違和感」「物理破綻」「テンプレ量産判定」で破綻する。人間の工数は以下の**7大レバレッジ関門**のみに集中投下する（定常運用の目標は 1本 3〜7.5時間）。

| 関門 | 工程 | AIが担う領域（8割） | 人間（日本語ネイティブ）が必ず担う領域（2割） |
| :--- | :--- | :--- | :--- |
| **Gate 1** | 企画・リサーチ | 競合動画文字起こし・構成解析、一次統計・論文PDF横断要約、企画案展開（`research_llm`） | **この回固有の問い・独自比較軸の選定**、一次資料3ソース以上の裏取り、YMYL×AIペルソナ地雷回避 |
| **Gate 2** | 構成・台本 | 5ブロック/I-PREP構成案、中盤ドラフト、表示用と読み上げ用の2ファイル分離、固い床の機械検証（`script_llm` / `qa_llm`） | **冒頭30〜90秒と中盤フックの音読リライト**、聴感・要所の「間」の調整、独自考察・具体例の加筆、数値照合 |
| **Gate 3** | 音声合成・QA | チャプター/段落バッチ生成、発音辞書適用、文字単位タイムスタンプ取得またはSTT照合（`tts_primary` / `stt_align`） | **1.25〜1.5倍速での全編耳チェック**（同音異義語・高低アクセント・息継ぎ・感情温度の崩れ摘出と局所再生成）、発音辞書への蓄積 |
| **Gate 4** | 映像・図解生成 | 音声FFprobe尺同期、Remotionコード生成＆チャプター単位レンダー、ネット収集素材の整理・配置（AI画像生成不使用） | **映像キュレーション（ボツ出し）**：視認性・文字溢れ確認、物理破綻のない素材選別、**5%程度の一次素材（実画面録画・一次資料強調等）差し込み** |
| **Gate 5** | NLE統合編集 | MCP/APIによるタイムライン自動構築、無音カット、BudouX文節改行字幕配置、仮BGM敷き込み、代表フレーム自動検品（`nle`） | **単調リズムの破壊**：0.1秒単位の「間」、重要結論直前のBGM引き算（約0.8秒無音）、BudouX誤改行（「志を／持って」等）の手動補修 |
| **Gate 6** | パッケージ | タイトル複数案生成、ネット収集素材を用いた Remotion `<Still>` サムネ構図ベース出力（AI画像生成不使用） | 競合10〜20本の検索結果と対比した**「逆張り」構図設計**、上限20文字・2行以内（推奨3〜10文字程度）のコピー、要素を絞った上で絵面・切り口・コピーが異なる複数案の最終承認 |
| **Gate 7** | 監査・証拠保全 | Git履歴・プロンプト・ライセンス記録・YouTubeアナリティクスログの整理 | **法務＆YPP最終監査**、AI開示トグル判定、限定公開24h前アップロードと自己診断申告、制作証跡フォルダ保全 |

## 3. 3層ビジュアル配分＆モジュラー分離パイプライン

### 3.1 脱AIスロップの3層ビジュアル比率（2D・コード駆動主力基準）
1. **第1層（40〜60%）：コード駆動モーショングラフィックス（Remotion）**
   - 動く数値グラフ、比較表、タイムライン年表、棒人間・図解アニメーション。データ推移や構造を分かりやすく可視化し、非テンプレ性と情報密度を高める（※何でもSVG自作に限定せず、実写・記事切り抜き等の第2層と柔軟に組み合わせる）。
2. **第2層（25〜40%）：記事見出し切り抜き・ネット収集実写素材・図版・資料キャプチャ**
   - AI画像生成は使用せず、ネット上から新聞・ニュース記事の見出し切り抜き、関連写真・図版、公的資料、フリー素材、実画面操作録画を積極的に収集・活用してビジュアル密度を高める（海外・国内先駆者の実務実態に倣い、丸ごと転載・有料記事全文掲載・長尺流用など致命的リスクのみ避けて過度に萎縮しない。動画画面内での著作権・出典表記は行わず、必要な出典は概要欄のみに集約する）。
3. **第3層（0〜20%上限）：実写ストック B-Roll 動画**
   - 冒頭導入や章転換の情景カットに限定（`planE_macro_econ` では `sha256` 検品＋3コマコンタクトシート目視を通過したフリー実写クリップを活用）。物理破綻や意図ズレのないカットのみ採用する。

### 3.2 「音声先行・Remotion 直接 MP4 出力」標準パイプライン
1. **TTS音声を先行生成**し、`ElevenLabs v4`（`with-timestamps`）の文字単位アライメントと `FFprobe` 実尺を JSON/TS タイムラインへ確定する。
2. 現行2ハーネス（`stickman_collage` / `planE_macro_econ`）では、`<Audio>` と抜け感字幕を含めて **Remotion から直接 MP4 を書き出す**（`planE_macro_econ` は直後に `pipeline/scripts/master_final.py` で `-c:v copy` 2パス loudnorm を適用）。
3. 長尺の手動微調整が必要な特例時のみ、チャプター単位の無音動画または透過 `ProRes 4444` (`yuva444p10le`) を書き出して NLE（DaVinci Resolve Studio 等）へ統合するオプションを採る。

## 4. CTV（テレビ大画面）× モバイル両立の技術規格

日本市場ではリビングのテレビ視聴（CTV）とスマホ通勤視聴の双方が主力であるため、以下をプロジェクト共通規格とする。

| 領域 | 規格値・数値基準 | 設計意図 |
| :--- | :--- | :--- |
| **解像度・FPS** | `1920 × 1080`（16:9）、`30 fps`（必要時60fps） | 長尺レンダー負荷と画質の最適バランス |
| **セーフゾーン** | **画面内側 90%**（上下左右 5% マージン）内に全図解・重要テロップを配置 | CTVのオーバースキャン（端切れ）およびモバイルUI干渉防止 |
| **タイポグラフィ（1080p基準）** | 見出し・強調数値：`48〜64 px` / ローワーサード：`36〜48 px` / ベース字幕：`24〜32 px` / CTA文字：`40 px`以上 | 遠距離TVと小型スマホ双方での即読性確保 |
| **字幕フォーマット** | **1行 14〜18文字目安・最大2行**、表示時間 **1.0〜3.0秒**、コントラスト比 **4.5:1以上**、抜け感アウトライン（帯ボックス禁止） | 読み上げ原稿との一言一句一致＋文節分割 |
| **音声マスタリング** | 統合ラウドネス **`-14.0 LUFS`**、トゥルーピーク設定 **`-1.4 dBTP`（MP4実測 `<= -1.0 dBTP`）**、**`48 kHz`** | YouTubeの「Downward-only」正規化で音量負けせず AAC ピーク跳ねも防ぐ値 |
| **サムネイル規格** | 出力 **`3840 × 2160`（4K）・50MB以下**（PC/API入稿時）、A/Bテスト時も最低 `1280 × 720` 以上厳守 | 4K CTV画質担保＆720p未満の強制480pダウンスケール回避 |
| **チャンネルバナー** | **`2560 × 1440 px`**（中央セーフゾーン **`1546 × 423 px`** 内にロゴ・更新頻度） | TV全画面からスマホまで見切れゼロ |
| **公開前バッファ** | 公開 **24時間以上前** に限定公開アップロードし、広告適合性自己診断を誠実に申告して緑アイコン確定後に公開予約 | 24時間追加審査対応＋継続的誠実申告による信頼スコア蓄積 |

## 5. 人間関与の監査証跡（Proof of Human Involvement）

万一の誤停止・再審査請求（5分未満の制作プロセス証明動画提出）に備え、毎エピソードの `episodes/productions/<id>/` と Git リポジトリに以下を自動・手動で保全する。
1. 人間が書き下ろした企画メモ・一次ソースURL一覧（`01_research_brief.md`）
2. 台本と人間リライトの修正差分（Gitコミット履歴）
3. 使用素材の出典メモ（概要欄用）、BGM・音声の商用ライセンスおよび制作ログ記録
4. Remotion ソースコードおよび NLE タイムライン構成プロジェクト
