# 05. 多層マネタイズ・企業案件・M&A資産化アーキテクチャ

日本市場の国内AdSense単価上限を前提としつつ、初期段階から「広告収益を全体の25〜35%の土台にとどめ、広告外収益（ASP・YouTubeショッピング・ハイブリッド企業案件・副産物転用メンバーシップ／デジタル商品）で総合RPMを2.5〜4.0倍化する」設計原則を定義する。具体的なASP単価や税務・市場数値は `docs/volatile/jp_market_monetization_rates.md` を参照すること。

## 2. 維持率を落とさない「中盤5パート送客トーク」とデバイス別4導線

### 2.1 禁止パターンと最適配置
- **3大NG：** ①冒頭30秒以内のPR、②ミッドロール広告直前/直後のPR連続配置（最低2〜3分の隔離バッファを設ける）、③「まとめます」終了合図後の長尺CTA。
- **最適位置：** 最初の知的納得（第1ペイオフ）を出した直後、かつ第2論点（オープンループ）を予告した直前にあたる **動画全体30〜45%地点**。尺はアフィリ・自社導線で **45秒以内**、企業案件で **60〜90秒（最大120秒、全体10%未満）**。

### 2.2 5パート構成トーク（Five-part read）
1. **Bridge（文脈接続）：** 本編論点から1文で自然にテーマ接続。
2. **Setup（前提導入＋冒頭開示）：** 「ここからは提携サービス／提供案件として〜」と最初に明示。
3. **Use（実検証・使用感）：** 運営側が実際に確認した挙動・仕様のみ誠実に語る（未体験の捏造厳禁）。
4. **Proof（能動的ビジュアル証拠）：** 単調なB-Rollではなく比較図・実操作画面・条件表で画面密度を維持。
5. **CTA（単一行動喚起）：** 1動画1主軸へ絞り、リンク先を統一した上で間を置かず本編へ復帰。

### 2.3 デバイス別4導線同期
- **スマホ・PC：** ①固定コメント（最優先1〜2件・UTM付）、②概要欄先頭3行（折りたたみ前にPR表記＋同一URL）、③YouTubeショッピングタグ（言及箇所15〜60秒表示）。
- **コネクテッドTV（CTV）：** リンククリック不可のため、自社LP・LINE等への誘導時は **動画後半に10〜15秒間のQRコード** を表示。

## 3. 企業案件実務と法務契約防衛

- **見積基準：** 登録者数単純掛け算より **CPV基準（直近30〜90日平均再生 × 係数）** が主流。初期は「固定＋成果」ハイブリッド提案で実績を積む。
- **必須インフラ：** YouTube Studioのパートナーシップ公式メディアキット（PDF出力）、ビジネス専用連絡窓口、過去動画の長期エバーグリーン再生カーブ。
- **着手前合意 Term Sheet 10項目：** ①納品形態（インテグレーション/専用）、②訴求ポイント3点以内、③挿入位置、④尺、⑤監修回数（原則「台本」「仮編集」の計2回）と返答期日、⑥二次利用権（**二次利用時もPR表記を維持する義務を明記**）、⑦競合排除期間、⑧専用URL/クーポン、⑨報酬・支払期日、⑩スケジュール。

## 4. スケール戦略（総集編・ポッドキャスト・多言語・M&A資産化）

### 4.1 総集編（60〜90分）＆ポッドキャストの安全4原則
作業用・睡眠用総集編はCTV滞在とPremium収益に有効だが、単純結合の乱発は「再利用／量産型コンテンツ」停止リスクを伴う。
1. **比率上限：** 公開本数全体の **15〜20%以下**（月1本上限または四半期単位）。最多再生・最新動画の主軸をオリジナル単発に保つ。
2. **トランスフォーメーション必須：** テーマ横断の新規導入ナレーション・章間ブリッジ解説、ダークモード背景再設計（静止画1枚放置は不可）、音量再調整、チャプター再設計。
3. **ポッドキャスト再生リスト優先：** 重複リスクを避けたい場合はファイル再結合ではなく、再生リストをStudio上で「ポッドキャスト」指定する。
4. **音声展開の役割分担：** YouTube Podcasts（YouTube Music連携）を最優先、Apple Podcasts Subscriptionsを補助とし、日本未対応の海外分配施策へ依存しない。

### 4.2 多言語展開（英語圏逆輸出）の原則
- **1チャンネル内での多言語音声トラック追加は非推奨：** 案C・案B/E・案Aは画面内の日本語文字・図解が主体であり、言語間の視聴維持率差が40%以上開くとチャンネル全体の推薦露出が低下する副作用が報告されている。
- **正解ルート：** 日本語本体の黒字化・型確立後、上位20%の勝ち企画とRemotionプロジェクトを流用し、画面テキスト英訳＋ネイティブ検収台本＋商用ライセンス音声で **「英語専用の別チャンネル」** として展開する。

### 4.3 M&A資産価値最大化・法務DD（初日仕込み4項目）
外注チーム化＋広告外収益3割超を法人格で整えると、属人型（EBITDA 2〜3倍）から高マルチプル評価（EBITDA 5〜7倍レンジ）が視野に入る。初日から以下を徹底する。
1. **ブランドアカウント運用必須化：** 個人Googleアカウントでは規約違反なしに所有権譲渡が困難。
2. **譲渡手順と制約の織り込み：** オーナー招待→7日待機→メインオーナー昇格→売り手離脱→AdSense切替（**変更は32日に1回制限**）。
3. **所有者/名義変更時のAI自動再審査防衛：** 過去動画に1本でもグレー動画があると名義変更時に一括停止され得るため、全過去動画のコンプラ定期監査と表現保証設計を行う。
4. **権利クリアランス台帳：** 業務委託契約書に「著作権（二次的著作物含む）譲渡・著作者人格権不行使特約」を必須記載し、BGM/フォント/音声の商用ライセンス証跡および使用素材の出典記録（概要欄集約元）を一元管理する。
