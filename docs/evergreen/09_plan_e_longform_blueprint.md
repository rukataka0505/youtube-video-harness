# 案E（`planE_macro_econ` v3.1）長尺制作ブループリント

`How Money Works` 型のシニカルな「お金とインセンティブの構造解剖」を、日本市場向けの長尺（15〜25分目安・水増し禁止）で制作するための設計指針。
マクロ経済・家計ニュースに限定せず、恋愛・医療・スポーツ・アート・エンタメ・冠婚葬祭・家電・歴史・教育・都市など幅広いジャンルを対象とする。

## 1. フォーマットの基本思想

- **本質構造**: 視聴者が直観的に持つ「常識や成功神話」をデータと構造で裏返し、誰が得をして誰が割を食うのかを冷徹に描く。
- **トーン**: 説教や怒り煽りを排し、静かな事実と数字のコントラストに軽い皮肉を添える（`configs/style_guide.md` 準拠）。
- **AI画像不使用**: 実写 B ロール・一次資料・新聞切抜き（ネット収集＋`sha256`検品）と Remotion 2D 描画のみで構築する。

## 2. 構成の指針（自由舞台・固定ブロックなし）

台本構成・導入の切り口・章立て・尺はテーマに合わせて自在に設計する（定型順や特定フレーズ型は固定しない）。
以下は案Eでよく効く構成要素のパレットであり、必要なものだけを組み合わせて使う。

- **導入の切り口**: 逆説的な価格・現象・思考実験・データなど、挨拶なしで最初から常識のズレを突きつける。
- **背景と実態データ**: 市場規模・一次統計・業界慣行を紙面・黒板・実写Bロール交差で提示し、表層の違和感を裏付ける。
- **構造の解剖（図解道具は任意選択）**:
  - 利益やコストの偏り（例: `allocation()`）、価格や制度によるふるい分け（例: `selection()`）、
    抜け出せないインセンティブ循環（例: `causal_gear_loop`）など、ネタに合う図解を自由舞台で表現する。
- **緩急と着地**: 視聴者の生活実感へ引き寄せつつ緩急をつけ、末尾は終了合図語を排して余韻・視点の置き土産・次動画導線へ繋ぐ。

## 3. 台本〜タイムライン連携（v3.1）

- `script-production` の固い床（`02_script_display.md` / `03_script_reading.md` 分離整合・ト書きゼロ・
  冒頭挨拶ゼロ・終了合図語ゼロ）を守り、`lint_script.py` で **ERROR 0** を通す。
- 視覚イベントを起こしたい語句は `chunks[].splits[].atText` に正確に切り出し、TS 側で `at()` により追従させる。
- 数値変更や前後文の差し替えが起きても、TSX を 1 行も書き換えずにビート・効果音・シーン境界・
  自由舞台の `ctx.cue()` が追従する状態を維持する。
- フック・リフック・核心・オチなどの山場は自由舞台 `type: 'custom'` で作品固有の画を設計し、
  プリセットは繋ぎに使う。

## 4. 画面・音響・監査規律

- **既定 TTS**: `ElevenLabs v4`（`eleven_v4` / `with-timestamps` 文字単位アライメント）。
- **背景極性とリズム**: `SURFACE_POLARITY` を交差させ（シーン内は `surfaceShifts`）、
  `PLAN_E_AUDIT_RULES` を `audit:plan-e --strict` で強制する。
- **セーフ領域と音響**: 字幕帯は `SUBTITLE_SAFE_BOTTOM` 系と `PLAN_E_STAGE_BOTTOM` の物理 clip で守り、
  効果音は `PROP_DEFAULT_SFX` / `hit()` のビート経由で Remotion `<Audio>` に一本化する。
- **最終音圧**: レンダ後の MP4 は `pipeline/scripts/master_final.py`（`-c:v copy` / 2パス `-14 LUFS / -1.4 dBTP`）で統一する。
