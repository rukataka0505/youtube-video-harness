# 日本市場データ・RPM・ASP単価・AdSense/税務実務（2026年11月版）

日本特化の市場環境数値、アフィリエイト条件、AdSense初着金手順、および2025〜2027年税務注意点をまとめる。

---

## 1. 日本市場視聴動向とジャンル別RPM目安

### 1.1 日本市場の規模・視聴特性（2026年秋）
- **利用者規模・CTV首位：** 国内月間利用者 **8,000万人超**（18歳以上ネット人口95%超）。REVISIO『コネクテッドTV白書2026』でテレビ画面視聴時間 **1日50.4分・第1位**（日本テレビ 47.3分を上回る）。YouTube Brandcast Japan 2026でCTV 3年連続1位、18〜29歳では地上波合計を超過。
- **視聴時間帯（RASA JAPAN 515人調査 2026/1）：** 就寝前 `44.85%`、日中休憩 `28.35%`、夕食〜入浴 `27.96%`、帰宅後 `25.83%` → 予約公開基準は **17:00〜18:30 JST**。
- **エンゲージメント率（Virev 2026/10調査・27,018ch）：** 日本の長尺中央値 **`1.12%`**（米国 `1.72%`・英国 `1.94%`・世界 `1.59%` より低いため能動的問いかけ・投稿タブ補完が必須）。10〜40分帯が最も反応が高い。
- **季節変動の罠：**
  - **年末年始（12/26〜1/3）：** 学習・ビジネス系は日常習慣崩壊により **通常比10〜15%水準まで急落**する事例あり。第6週は「年次総まとめ・リビングTV向け大型企画・新年習慣テーマ」へ切り替える。
  - **1月RPM下落：** AIR実測で11月ピーク（`$2.35`）から **1月は最低（`$1.56`、約34%減）** へ落ち込む。1〜2月は新NISA・確定申告・新年自己投資のASP強化で補填する。

### 1.2 日本 vs 英語圏 RPM目安（出典差異を踏まえた保守的レンジ）
※YouTube公式はジャンル別RPMを非公表。下記は2026年集計データの参考レンジ。
- **全体平均目安：** 日本長尺中央値 **494〜500円**（virev.ai 118人集計）、Shorts中央値 **15円**（長尺の約1/40）。Dynamoi 86市場集計（参考値）では日本全体 Creator RPM **`$2.52`** に対し、米国 `$4.96`（約2.0倍）、豪州 `$6.77`（約2.7倍）、カナダ `$4.78`、英国 `$3.98`。
- **採用フォーマット別・保守的想定レンジ：**
  - **案C（心理・行動科学）：** `500〜950円`（保守基準 600〜720円）
  - **案B / E（2D棒人間・比喩経済）：** 一般雑学寄り `250〜550円`、15分超×金融・経済テーマ寄せ `600〜1,000円+`
  - **案A（企業興亡・ビジネス）：** `600〜1,200円`（BtoB・投資層集中時）

## 2. 国内主要ASP・YouTubeショッピング・案件／外注／M&A相場

### 2.1 国内ASP（登録フェーズ二段階設計）
1. **1,000〜9,999人フェーズ（先行導入）：**
   - **A8.net：** 登録審査なし。VPN（NordVPN / MillenVPN 3,500円等）・学習・転職・SaaS。SNS掲載可否を案件ごと確認。
   - **もしもアフィリエイト：** W報酬 `+12%`・Amazon迂回提携・GFS無料講座（旧バフェッサ、有料6ヶ月69.8万円の存在開示必須）。
   - **Amazonアソシエイト（直接）：** 登録180日以内3件適格販売が必要。特別料率は **Audible 2,000円 / Kindle+（2026年10月改称）1,000円 / Amazonビジネス 3,000円**（※2024年8月に1商品1,000円上限撤廃済み）。
   - **アクセストレード（証券最多クラス32件）/ afb（最低777円・消費税10%上乗せ・翌月末払）/ TGアフィリエイト（SBI・楽天証券強み）：** 口座開設＋入金達成型 `5,000〜15,000円` 相場、会計SaaS `3,000〜8,000円`。
   - **YouTubeショッピング（楽天 2026/2〜 / Yahoo! 2026/9/25〜）：** 基本 `2〜4%`（現在コミッション100%還元の一時的優遇中・Studio画面で参加要件確認）。
2. **1万人突破後解禁：**
   - **バリューコマース**（YouTube連携審査要件：登録者 **10,000人以上**）および招待制クローズドASP（レントラックス / felmat 等で特単交渉）。
3. **企業案件窓口：** toridori base（1,000人目安〜）、BitStar Match、YouTube Studio「Creator Partnerships」公式メディアキットPDF。小規模期相場は「直近平均再生 × 2〜15円」または「固定2〜4万円＋成果報酬ハイブリッド」。
4. **ポッドキャスト＆デジタル商品：** **Spotify SPP / Memberships（90%還元）は2026年11月時点で日本未対応**。YouTube Podcasts（最優先）＋ Apple Podcasts Subscriptions（年会費2,400円）＋ note（手取り約85.5%）/ Amazon KDP（2026/7改定で70%印税上限 `1,250円 → 1,650円` へ拡大）。

### 2.2 フル外注原価＆M&A評価相場目安
- **15〜25分フル外注相場：** 案C・比喩経済で約 `30,000円/本`、案Aで約 `60,000円/本`（広告外収益で損益分岐再生数を60〜76%圧縮可能）。
- **M&A相場：** 個人売買は月間営業利益の `10〜24ヶ月分`（実績事例：7.4〜16ヶ月分）、法人株式譲渡で制作チーム化＋広告外収益3割超を達成すると **EBITDA 5〜7倍** が評価帯となる。

## 3. 日本居住者のAdSense初着金・税務・インボイス最新実務

### 3.1 AdSense〜初着金 5大ボトルネック対策
1. **国・IP一致＆重複AdSense排除：** YouTube居住国・AdSense国・お支払いプロファイル国・**申請時物理IP（VPN厳禁）**の4点を日本に統一。過去の休眠AdSenseがあると重複エラー（リンク変更は32日制限）。
2. **本人確認書類：** **マイナンバーカード** または **運転免許証** のみ使用（住所欄のない日本パスポート・紙の通知カードは却下リスク大）。本人確認完了がPIN発送トリガー。
3. **米国税務（W-8BEN）：** Foreign TIN 欄にマイナンバーを入力し日米租税条約（非課税）適用（3年毎末更新）。漢字プロファイルとローマ字W-8BENの氏名不一致エラーに注意（本人確認後にローマ字整合または氏名証明提出）。
4. **シンガポール居住者証明書：** 支払元は Google Asia Pacific Pte. Ltd.。所轄税務署へ「居住者証明書交付請求書」を請求（発行約12日〜2週間）。**スマホ撮影は却下されるためスキャナで鮮明PDF化**して提出（完了まで実測約1か月）。
5. **PIN 4か月リミット＆着金ライン：** 基準額（約10米ドル相当）到達後に国際郵便でPIN発送。**初回発行から4か月未入力・3回誤入力で広告停止**。銀行テスト入金確認も3回制限。残高 **8,000円以上** かつ毎月20日までに全保留解除で21〜26日支払処理。

### 3.2 消費税・インボイス・青色申告（2025〜2027年改正）
- **広告収益の消費税区分：** Google直接契約は「国外取引（不課税）」整理が実務標準（※令和7年1月8日国税不服審判所裁決により、**専属MCN経由の分配は国内課税売上10%認定リスク**があるため直接契約を維持）。
- **海外AIツール仕入税額控除：** 請求前にBilling設定へ宛名・事業情報を登録し適格請求書PDFを保存（事後修正不可）。登録番号例：OpenAI（`T3700150133253`※自身の請求書を国税庁サイトで要照合）、Anthropic（`T7700150134388`、2026/4/1〜課税）。未登録国外消費者向けサービスには80%→70%（2026/10〜）経過措置が適用されない。リバースチャージは一般課税で課税売上割合95%未満のみ対象。
- **開業届 vs 青色申告の期限ズレ（2026年改正）：** 2026年1月以降、開業届は翌年3月15日迄へ延長されたが、**青色申告承認申請書は従来通り「開業日から2か月以内」**（未提出で65万円控除喪失）。さらに **2027年分から書面提出の青色控除が10万円へ減額され、e-Tax＋要件充足で最大75万円へ拡充**（2割特例は2026年分終了予定）のため、開業2か月以内に e-Tax で同時提出すること。
