## 1. 最重要結論（ハイブリッド・ルーティングの原則）

総合ベンチマーク順位やトークン単価表だけで単一モデルに寄せると、**手戻り・レビューノイズ爆増・コスト逆転**を高確率で踏む。実戦最適解は以下の工程別ハイブリッドである。

- **審美眼・初動設計（`STYLE.md` / ヒーロー）・初回完動・高難度監査・要約:** `Claude Opus 5.5`
- **日常主力・長文リポジトリ横断（256K〜1M）・書き出しMP4/音声ネイティブ検品:** `Gemini 4 Neon`
- **確定設計下の高速カット量産・全PR一次レビュー:** `Claude Sonnet 5.5`
- **仕様100%確定の単体編集・図表/スクショ模写・超低コスト補助レビュー:** `GPT-6.2 Sol`
- **並列ファイル探索・疎結合カットの `/swarm` 並列ワーカー・高速2Dドラフト:** `Gemini 4 Hydrogen`
- **Remotion Studio WebMCP 直結操作・特殊物理VFX・深層バグ発掘（スポット）:** `GPT-6.2 Astra`

## 3. 推論強度（Effort / Thinking）4大鉄則（上げすぎ劣化＆コスト逆転）

1. **Claude Sonnet 5.5 は `xhigh`/`max` 禁止 → `Opus 5.5 (medium)` へ即昇格:**
   - CursorBench で Sonnet `xhigh`（`$3.88`）より Opus `medium`（`$2.91`）の方が安く同水準。AA 評価の `max` では Sonnet が Opus と同等〜高額化し、FrontierCode は `xhigh` 52.1% → `max` 46.2%（`-5.9pt`）に暴落する（不要なレビューサブエージェント乱立・128K出力枯渇）。
2. **GPT-6.2 Astra / Sol は `xhigh` 上限、`max` 非推奨:**
   - Astra は FrontierCode-AA 2.0 で `xhigh` 49.0% → `max` 45.4%（`-3.6pt`）に劣化し費用1.59倍。Sol も Coding Agent Index で `xhigh` 49.8 → `max` 48.6 に低下。PRレビューは Sol `low`（`$0.83`・Precision 32.7%）→ `high` でコスト+38%・Nitpick 3倍増に対し追加検出1件のみ。
3. **Gemini 4 Neon は既定 `high` 維持、Hydrogen は `xhigh` 厳禁:**
   - Neon `high`（60点・`$3.74`・14.8分）→ `xhigh`（61点・`$6.44`・22分）は `+1pt` のためにコスト1.72倍。Hydrogen `xhigh` は極端な饒舌化（304M出力tok、54点・`$3.16`・16.9分）で Sol `high`（55点・`$0.56`・4.6分）や Neon `medium`（55点・`$1.90`）に全面敗北。
4. **GPT-6.2 系の 272K トークン料金崖:**
   - 入力が 272,000 tok を超えるとリクエスト全体の入力・キャッシュが2倍、出力が1.5倍へ急騰する。超える見込みなら事前フィルタするか 1M フラット料金＋長文探索95.2% の **Gemini 4 Neon (`high`)** へ逃がす。

## 6. 共通ガードレール＆22暗黙知の必須チェック（抜粋統合）

1. **自己採点の禁止（クロスモデル監査）:** 全主要モデルに強い自己採点バイアスがある（Epoch AI 実証）。実装モデルと別モデル（例：`Neon` 実装→`Opus` 監査、`Opus` 実装→`Neon` MP4検品）またはクリーンコンテキストの独立 `@verifier` を必ず品質ゲートに置く。
2. **Remotion 決定論的実装の3制約:** 公式 `remotion-dev/skills` 準拠で ①CSS transition / Tailwind animation 禁止（`useCurrentFrame()` / `interpolate()` / `spring()` のみ）②`transform` 一括指定ではなく個別の `scale`/`translate`/`rotate` 優先 ③明示指示前の無断 `remotion render` 禁止（Studio／`remotion still` コンタクトシート先行）。
3. **参照デザインの4層渡し:** 形容詞指示を禁止し、①構造スケッチ（解像度・fps・フレーム尺・セーフエリア数値）②役割キャプション付きムードボード ③名指し禁止リスト ④確定 `STYLE.md` ＋2段階スチル検査（P0/P1潰し→本レンダー）で渡す。
4. **確率的記憶（200行上限）と決定論的強制の分離:** `AGENTS.md` / `CLAUDE.md` は 80〜150行（最大200行）の目次ルーター＋数値規約（関数50行・ファイル300行上限・要求外追加禁止）に留め、本番レンダーや保護ファイル書込禁止などの絶対境界は Hooks / Permissions で100%機械強制する。
5. **マルチターン API は厳格な追記専用（Append-Only）:** 過去のメッセージ・思考ブロック・`thought_signature` の書き換え・削除を全系統で禁止する。
