# YouTube プラットフォーム規約・アルゴリズム・API仕様（2026年11月〜2027年2月）

プラットフォーム側の仕様変更・改定スケジュール・API制限をまとめる。数字や締切は公式更新に追従して差し替えること。

## 1. 2027年2月1日 YPP大改定と2027年1月31日逆算タイムライン

### 1.1 改定内容（2026年8月10日発表・2027年2月1日発効）
- **新規広告収益化（Tier 2）要件倍増：** 登録者 1,000人据え置き、過去365日の公開長尺有効総再生時間 **4,000時間 → 8,000時間**（または過去90日Shorts **1,000万回 → 2,000万回**）。
- **早期アクセス（Tier 1：ファンファンディング・ショッピング等）：** 登録者 500人・公開動画 3本（90日）・有効総再生時間 **3,000時間**（またはShorts 300万回）は改定後も据え置き。
  - **【重大注意】** 1月中に Tier 1 を通過しても、2月1日以降に広告収益（Tier 2）を解放する場合は **8,000時間が要求される**（免除にならない）。
- **既存パートナー要件：** 2027年1月31日までに Studio の更新利用規約モジュール（Watch Page / Shorts / Commerce 等）へ同意必須。未同意時は2月1日から対象収益支払いが一時停止する。
- **2月1日以降の新アクティブ維持要件：** 過去365日 1,000時間、過去90日 Shorts 100万回、または **90日ごとに長尺2本／Shorts 5本投稿** のいずれかを満たさないと資格維持が危うくなる（6か月放置で自動除外リスク）。また Shorts プール収益は直近90日 1,000万回未満で一時停止（長尺には影響せず、達成で自動再開）。

### 1.2 2027年1月31日 23:59 UTC 逆算タイムラインと遅延リスク
- **2/1跨ぎの「審査中」リスク：** AIR Media-Tech は「1/31 23:59 UTC までにステップ1・2を完了してステップ3審査中に入っていれば旧4,000時間基準で審査される」と案内する一方、YouTube公式ヘルプ上には**月跨ぎ審査の明文保証がない**。さらに1月中に1回でも否認されると**初回30日間の再申請待機**（2回目以降90日）により自動的に 8,000時間基準へ転落する。
- **三重の遅延：** ①Earnタブ有効時間反映ラグ（**2〜7日**、実務5〜6日）、②ステップ2（AdSense新規作成・承認：数日〜**最大2〜3週間**、既存有効AdSenseなら数時間〜1日）、③ステップ3本審査（実績1日〜1週間、公式目安**約1か月**、AI境界事例で2〜3週間〜長期化）。

## 2. 2026年後半の重要メトリクス・アルゴリズム・機能アップデート

1. **全フォーマット「1フレーム目カウント」実装（2026年8月24日〜27日頃）：**
   再生開始1フレーム目（自動再生・ホバー含）で公開「視聴回数」が加算される仕様へ変更。見かけの再生数が増えてエンゲージメント率や見かけRPMが下がって見える錯覚が生じる。**YPP・収益・CTR・AVD・維持率は「エンゲージビュー（Engaged Views）」基準**で評価されるため、分析は必ず詳細モードのエンゲージビューで行う。
2. **テレビ共視聴（Co-Views）合算（2026年11月16日開始）：**
   CTV視聴に対し統計推定の複数人視聴係数（公式例 1.10〜1.44）を掛け、公開再生数だけでなく**Analytics の「総再生時間」にも加算**する仕様へ変更。**ただし YPP 4,000時間要件と広告収益には一切算入されない**。よって Analytics 上は **4,600〜4,900時間以上** を安全目標とし、最終確認は必ず **［収益化（Earn）］タブ** で行う。
3. **「非真正コンテンツ」3類型明文化（2026年7月16日）＆ AI自動ラベル（5月27日〜）：**
   ①汎用/反復テンプレート、②不快・過剰煽り、③センシティブ領域（金融・医療・法律・政治）のAIペルソナが明確化。また C2PA / SynthID を読み取って未申告のリアルAI映像へ自動ラベルを付与（開示漏れ反復で制裁、開示自体は露出に影響なし）。
4. **Shortsオリジナル優遇（2026年10月1日）：**
   *Prioritizing original content on Shorts* 適用。転載・単純切り抜き・焼き直しは初動評価が厳しく、数日〜1週間様子見される傾向が強まった。
5. **YouTube Premium Lite 拡大（2027年2月1日〜）：**
   通常Premium（純収益30%プール）の2倍となる **純収益60%が専用クリエイタープールへ配分**され、長尺動画に **55%** が割り当てられる。長時間視聴される教養長尺に追い風。
6. **ハイプ（Hype）日本展開＆有料Jewels対応：**
   YPP加入・登録者500〜50万人の長尺（公開7日以内・誇大クリックベイト除外）が対象。500人規模では50万人規模の **150倍ポイント倍率**（1ハイプ＝7,500pt vs 50pt）が付き、探索リーダーボードや「Hyped」バッジで拡散を後押しする。
7. **「Test & Compare」仕様：**
   0人chでも上級者向け機能解放で利用可能。勝者はCTRでなく「インプレッションあたり視聴時間シェア」で自動判定。**テスト用サムネ1枚でも 1280×720 未満だと全案が 480p にダウンスケールされる** 罠に注意。
8. **非アクティブ登録者への通知停止（2026年4月21日〜）＆ チャンネル概要欄監視（5月〜）：**
   1か月未視聴の登録者へのプッシュ通知が自動停止される（投稿タブ等の接点重要性増大）。チャンネル概要欄もガイドライン直接監視対象。

## 3. YouTube Data API v3 仕様・既知障害（2026年6月〜11月）

| 項目 | 2026年11月時点の仕様・障害情報 | `pipeline/` での対処 |
| :--- | :--- | :--- |
| **細分化クォータ4バケット**（2026年6月1〜3日刷新） | ①`search.list` 専用枠：**100回/日**（50件/回・合計500件打切）、②`videos.batchGetStats` 専用枠：**10,000回/日**（安全策 50 ID/回）、③`videos.insert` 専用枠：100回/日、④一般共有プール：**10,000ユニット/日**。リセットは **PT 00:00（JST 16:00/17:00）**。 | `configs/outlier_thresholds.yaml` に安全上限を設定し、`YouTubeQuotaLedger` でバケット別管理＋サーキットブレーカー停止。 |
| **YouTube公式RSS障害**（2025年12月〜） | 毎日 UTC 09:00〜12:00 前後に404/500多発・DC IP制限報告。 | RSSに依存せず `playlistItems.list`（`UULF`/`UUSH`、404時 `UU` フォールバック）を主軸とする。 |
| **`paidProductPlacementDetails` 不具合**（2026年11月3〜16日） | API経由設定のStudio反映不具合（Issue `#581064689`）および未指定デフォルトfalse廃止。 | 単一フラグに依存せず「API＋日米PR表記正規表現＋SponsorBlock＋Gemini音声」の4信号融合で案件検知。 |
| **`commentThreads.list` 不具合** | `searchTerms` と `order="relevance"` 併用で空レスポンスを返す既知不具合。 | `searchTerms` を使わず `order="relevance"` 単体で取得し、ローカルでキーワード・重み抽出。 |
| **Gemini YouTube URL入力** | 2026年11月時点で公式ドキュメント上 **Preview扱い**（公開動画のみ対応）。 | `400/403` は動画単体スキップとして隔離し、課金挙動は `usage_metadata` で定期検証する。 |
