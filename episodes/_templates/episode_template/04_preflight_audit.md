# Gate 7: 公開前 法務・ライセンス・YPP完全防衛監査（04_preflight_audit）

根拠：[docs/evergreen/01_guardrails_legal_ypp.md](../../../docs/evergreen/01_guardrails_legal_ypp.md) / [.agents/skills/legal-ypp-guardrail/SKILL.md](../../../.agents/skills/legal-ypp-guardrail/SKILL.md)

## 1. 一次情報・素材引用・企業法務
- [ ] 社名・年号・財務数値・論文データを人間が一次情報（3ソース以上）で直接照合した。
- [ ] ニュース見出し切り抜き・関連写真・図版・フリー素材等を解説補強として活用しつつ、有料記事の全文掲載・記事や他動画の丸ごと転載・単一書籍の丸ごと要約・一般SNS反応集量産になっていない（先駆者チャンネル準拠の実務判断）。
- [ ] 出典・クレジット表記が必要な引用素材・統計・公的データ等は、動画画面内（隅テロップ等）には出さず、YouTube概要欄のみに集約して記載した。
- [ ] （企業言及時）経営者人格攻撃・未確定犯罪断定を排除し、対象企業の競合アフィリエイト／PRリンクを貼っていない。

## 2. 音声・技術・BGMライセンス
- [ ] 音声：実在企業・人物批判動画に既製 `ACML 1.0` モデルを使っていない（自声クローン／CC0／許諾済み商用のみ）。著名人酷似声ではない。
- [ ] 素材方針：AI画像生成は動画素材・サムネイルともに使用していない（ネット収集素材＋Remotion 2D/SVGで構成）。音声・B-Rollツール等は商用利用可能な有料プラン上で運用した。
- [ ] Remotion / フォント：SIL OFL / Apache 2.0 フォントのみ使用し、コード関与者は外注合算3名以下。
- [ ] BGM：Content ID クリアランス済み商用ライブラリ（Safelist登録済み）のみ使用（Suno/Udio未使用）。

## 3. YPP非真正コンテンツ対策・表現・パッケージ
- [ ] 金融・医療/健康・法律・政治で架空AI専門家ペルソナが登場しない。
- [ ] 直近3本の連続再生でも「テンプレ量産・名詞入替」に見えない差別化（骨格・図解・固有概要欄）がある。
- [ ] 冒頭30〜90秒は人間が音読リライト済み、結論・反転・オチの要所で「間」が効いている、音声1.25〜1.5倍速耳チェック完了。
- [ ] 動画画面内・サムネ内に出典・クレジット表記がない（概要欄のみに集約）。
- [ ] PR/アフィリエイトがある場合、紹介中常時テロップ＋概要欄1〜3行目明記＋必要時「有料プロモーション」ON（金融時はリスク注記同等サイズ）。
- [ ] AI開示トグル：リアル調AI B-Roll/実在改変を含むなら `ON`、2D図解＋自声クローンのみなら `OFF`。
- [ ] 技術規格：90%セーフゾーン確認、サムネ `build_thumbnail.py`（4K `3840×2160` 50MB以下 / A/B最低 `1280×720` / `168×94px` スクイント / 比較シートクロス目視QA）確認、音圧 `-14.0 LUFS` / `-1.4 dBTP`（実測 `<= -1.0 dBTP`）、公開24時間以上前限定公開＋自己診断誠実申告。
