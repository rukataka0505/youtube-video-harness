## 1:10〜1:50 査読論文＆経済学による種明かし第1弾

- **c07 [種明かし1：ロゴの大きさと4分類の逆転]**
  答えは、2010年にマーケティングの学術誌へ載った論文にあります。消費者を資産と見栄の強さで4つに分けると、面白い逆転が起きます。本物の超富裕層ほど、ロゴのない静かな高級品を好むのです。同じ層にしか分からない素材や仕立てで、さりげなく仲間を見分けます。

> - **想定尺:** `1:10〜1:29`（19s） / **背景極性:** 明色反転（`causal_gear_loop` / `paper`）
> - **シーン設計:** 紙面ベースの因果ステージ。左NPC「超富裕層（Patricians / 無地・クワイエット）」と右NPC「背伸び層（Parvenus・Poseurs / 巨大ロゴ）」を対比し、上下パイプで承認シグナルの非対称ループを描画
> - **画面表示（名詞句・数値のみ）:** `資産 × ステータス欲求 4分類` / `クワイエット・ラグジュアリー` / `無地・素材識別`
> - **SFX:** `paper_snap`＋`mech_slide`＋`soft_pop`

- **c08 [種明かし2：巨大ロゴの買い手とヴェブレン財]**
  では、一目でわかる大きなロゴを買うのは誰か。周囲に違いを見せつけたい新興層と、背伸びする中産階級でした。ここに、経済学者ヴェブレンが見抜いた「ヴェブレン財」の法則が重なります。たいていの商品は値上げすると売れませんが、見せびらかすための商品は真逆です。高くなるほど希少価値が上がり、かえって欲しくなるのです。

> - **想定尺:** `1:29〜1:50`（21s） / **背景極性:** 明色（`whiteboard_trend`）
> - **シーン設計:** ホワイトボード上で「通常財（価格↑で需要↓）」の青線と「ヴェブレン財（価格↑で需要↑）」の赤線を対比描画し、右上がり頂点を赤丸強調
> - **画面表示（名詞句・数値のみ）:** `ラウド・ラグジュアリー` / `ヴェブレン財` / `価格↑ → 欲求↑`
> - **SFX:** `marker_draw`＋`price_ping`＋`soft_pop`
