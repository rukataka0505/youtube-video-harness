# 案E（`planE_macro_econ` v3.1）人間最終 QA チェックリスト

数値監査・スキーマ検証・文字時刻計算は自動検証完了済み。本表は**人間の目と耳だけで確認する判断項目**のみを扱う。

## 1. 視覚バランス・可読性

- [ ] 168×94px スクイント相当（縮小プレビュー）でも主役小道具・図解の構図と主要数値が瞬時に判別できるか。
- [ ] 字幕帯とカード・判子・値札・グラフ軸が重なって視認性を損ねていないか。
- [ ] 紙面・黒板・Bロール間の背景切替に唐突な視線ジャンプや目に刺さる色の暴れがないか。

## 2. 表現の固有性

- [ ] フック・核心・オチの画がこの回の題材でしか成立しない固有の発想になっているか（他回の焼き直しでないか）。
- [ ] 動きが語りの意味を運んでいるか（飾りの揺れ・意味のない出現で埋めていないか）。

## 3. 実写・一次資料の意味一致（AI画像排除）

- [ ] `contact_sheet.png` の各クリップ3コマすべてが台本の `intent` と一致し、関係ない人物・ロゴ・透かしがないか。
- [ ] 低解像度・引き伸ばし劣化・AI生成風の不自然な画像が1カットも紛れ込んでいないか。

## 4. 経済ストーリー・皮肉・法務

- [ ] 「金が誰から誰へ流れたか」「誰がふるい落とされたか」を一目で納得させる演出になっているか。
- [ ] 冒頭フックから皮肉な小オチまでのリズムが重厚かつシニカルで、AI 臭い道徳まとめや常套句が残っていないか。
- [ ] 名誉毀損・不競法違反・断定的投資助言がなく、出典表記はすべて概要欄のみに集約されているか。

## 5. 音声・聴き心地

- [ ] ナレーションの読み間違い・不自然な間・語尾切れがなく、BGM やビート SFX が声を邪魔していないか。
- [ ] マスタリング後の試聴で他のシーンより極端にうるさい／小さい箇所やクリップ歪みがないか。
