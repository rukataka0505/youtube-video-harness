# Plan C (Collage) フォントライセンス一覧

本ディレクトリ（`studio/public/fonts/plan_c/`）に同梱されている全フォントサブセット（`.woff2`）および `fonts.css` は、Google Fonts より配布されている以下のオープンライセンス書体で構成されています。

| フォントファミリー | ライセンス | 用途 |
| :--- | :--- | :--- |
| `Zen Maru Gothic` (700, 900) | **SIL Open Font License 1.1 (OFL 1.1)** | 手描き風丸ゴシック見出し・図解ラベル |
| `Yomogi` (400) | **SIL Open Font License 1.1 (OFL 1.1)** | 手描き棒人間看板・吹き出し・手書き注釈 |
| `Noto Sans JP` (700, 900) | **SIL Open Font License 1.1 (OFL 1.1)** | ベース字幕（CleanSubtitle）・汎用ゴシック見出し |
| `Noto Serif JP` (700, 900) | **SIL Open Font License 1.1 (OFL 1.1)** | 報道紙面カード見出し・引用本文 |
| `Playfair Display` (700, 900) | **SIL Open Font License 1.1 (OFL 1.1)** | 新聞・英字紙面マストヘッド・装飾セリフ |

## 注意事項
- 上記5書体はいずれも SIL OFL 1.1 に基づき、ローカル・Docker・クラウドレンダリング環境への同梱および商用利用が許可されています。
- Adobe Fonts および Morisawa Fonts 等の商用デスクトップ契約フォントを本ディレクトリへ追加・同梱することは厳禁です。
